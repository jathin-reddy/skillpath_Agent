### Agentic characteristics
- Receives contextual user input.
- Uses a role-specific knowledge base.
- Makes a decision based on weighted requirements.
- Calls specialized processing stages/tools.
- Produces an actionable plan rather than only an answer.
- Produces measurable intermediate output (readiness score).
